Simple algorithm; just have to keep track of _how many times `nums[i] < nums[i-1]`_ and make sure that the _number of occurences_ is **less than or equal to 1**
(also remember to compare `nums[0] < nums[nums.size()-1]`)

## code

```cpp
class Solution {
public:
    bool check(vector<int>& nums) {
        int count = 1;
        for (int i = 1; i < nums.size(); ++i) {
            if (nums[i] < nums[i-1]) {
                --count;
                if (count < 0) {
                    return false;
                }
            }
        }
        if (nums[0] < nums[nums.size()-1]) {
            --count;
            if (count < 0) {
                return false;
            }
        }
        return true;
    }
};
```

### complexity

> - Time: `O(n)`
> - Space: `O(1)`
